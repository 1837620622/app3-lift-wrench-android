# 旧桌面版归档说明

旧桌面版 PyQt/PySide 方案已停止作为主线开发。

当前正式主线为：

```text
App3Android/
```

归档原因：

- 现场最终使用安卓手机直接连接扳手 Wi-Fi，更符合离线地铁工点环境。
- 桌面版需要 Mac/Windows/Linux 运行时和额外网络转发，现场链路更复杂。
- 旧桌面项目包含模拟模式、历史调试截图、数据库和原始帧日志，不适合混入正式 Android APK 主线。

处理规则：

- 新仓库只保留 Android 主线代码、项目文档、协议说明和总结报告。
- 旧桌面代码保留在本机 `顶升扳手采集软件（作废）/`，不纳入新 Android 仓库。
- GitHub 上旧私有仓库应标记为 archived，作为历史参考，不再继续开发。
