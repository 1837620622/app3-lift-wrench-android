# UI 与交互设计说明

## 使用场景

现场工人需要在地铁环境中快速判断当前点位是否接近平衡。手机可能固定在工具、支架或附近可视位置，屏幕必须在横屏下清楚显示关键数值和趋势曲线。

## 设计原则

- 横屏优先，兼容不同安卓手机屏幕。
- 所有核心数值醒目显示，不让工人寻找信息。
- 顶升力是主读数，尺寸和颜色优先级高于其他辅助数值。
- 扭矩、转角、顶升力、压力、位移必须同时可见或快速切换可见。
- 状态条同时显示现场判断、最终结果和平衡趋势。
- 现场工作台只负责连接、状态和快速读数，不在主界面承载曲线阅读。
- 曲线大屏必须是单独页面，通过“进入曲线大屏”“扭矩曲线”“压力曲线”进入。
- 曲线大屏默认同时显示扭矩、顶升力、浮置板压力三条曲线，顶升力优先放大。
- 曲线图必须显示横轴转角、纵轴单位、采样点数、当前值和趋势判断。
- 现场按钮要短、准、可理解，不写协议细节或技术缩写。
- 正式界面不保留模拟按钮，避免现场误触和记录混淆。
- 危险动作按钮需要颜色和布局区分。
- 小屏下允许上下滚动，但按钮不能被裁掉，文字不能溢出。

## 核心按钮

| 按钮 | 当前行为 | 风险 |
|---|---|---|
| 连接扳手 | TCP 连接当前 IP/端口 | 中 |
| 断开连接 | 关闭 TCP | 低 |
| 手机控制 | 发送手机控制启用帧 | 中 |
| 关闭控制 | 发送手机控制关闭帧 | 中 |
| 正向顶升 | 发送正转启动帧 | 高 |
| 反向回退 | 发送反转启动帧 | 高 |
| 停止扳手 | 发送停止帧 | 高 |
| 保存记录 | 更新会话摘要 | 低 |
| 确认平衡点 | 标记最新采样点为平衡点候选 | 中 |
| 检查连接 | 发送连接保活帧 | 低 |
| 确认规则 | 显示结果确认的自动处理规则 | 低 |
| 对时规则 | 显示时间校准的自动处理规则 | 低 |
| 曲线大屏 | 打开独立曲线页面 | 低 |

正式版本中，高风险按钮应增加二次确认或长按确认。

主界面不显示 `0x12`、`ACK`、`NAK` 等协议词。右侧“设备”页面保留原始 HEX 和详细回传内容，供调试和报告使用。

## 曲线显示

曲线指标：

- 扭矩-转角。
- 顶升力-转角。
- 浮置板压力-转角。

真实曲线应呈现：

- 扭矩和角度来自 `0x12` 过程帧或最终 `0x15` 结果帧。
- 顶升力和压力必须在标定后显示。
- 异常时可显示回落、超限或滑移风险。

实时工作台已把趋势从调试用“原始角度”替换为现场更直观的“趋势”，优先按顶升力判断；未标定或没有力值时退回扭矩趋势。主界面不再显示曲线图，只显示顶升力主读数、连接状态和进入曲线大屏的按钮。曲线大屏独立占满一屏，主曲线显示当前选择指标，另外两条曲线同步显示在旁边或下方，点击小曲线可切换主曲线。

曲线图已补充坐标轴、单位、采样数和空数据提示；未收到真实扳手数据时只显示等待状态，不接入模拟数据。

## 待优化方向

- 工作台和曲线大屏需要真机截图复核；当前不再启动模拟器，避免 Mac 卡顿。
- 小屏手机需要检查文字是否溢出。
- 按钮需要按危险程度重新分组，避免误触正转/反转。
- Wi-Fi 诊断状态需要做成清晰步骤条。
- 未标定时力和压力应明确显示“未标定”，不要让工人误认为正式值。
