# 工程公式与标定边界

## 计算链路

扳手提供扭矩和角度，软件需要计算：

```text
扭矩 + 转角
  -> 顶升位移
  -> 顶升力
  -> 浮置板压力
  -> 平衡点和预警状态
```

当前 Android 正式界面不输出未标定的工程力值。正式工程值必须接入实测标定参数后才能启用。

## 位移公式

```text
displacement_mm = angle_deg / 360 * screw_lead_mm / gear_ratio + zero_offset_mm
```

参数含义：

| 参数 | 单位 | 说明 |
|---|---|---|
| `angle_deg` | degree | 扳手转角 |
| `screw_lead_mm` | mm/rev | 丝杆导程 |
| `gear_ratio` | dimensionless | 输入转角与丝杆实际转角的比值 |
| `zero_offset_mm` | mm | 零点偏移 |

标定前示例参数：

```text
screw_lead_mm = 5.0
gear_ratio = 1.0
zero_offset_mm = 0.0
```

## 丝杆物理力模型

理论力公式来自理想丝杆功率平衡：

```text
force_kN = 2 * pi * torque_Nm * efficiency * gear_ratio / screw_lead_mm
```

由于 `1 N*m / mm = 1000 N`，公式最终可直接得到 kN。

标定前示例参数：

```text
efficiency = 0.82
screw_lead_mm = 5.0
gear_ratio = 1.0
```

该公式量纲闭合，但效率、导程、传动比和扳手输出路径必须由厂家结构参数或现场标定确认。

## 压力公式

```text
pressure_mpa = force_kN * 1000 / effective_area_mm2
```

依据：

```text
1 N/mm2 = 1 MPa
```

标定前示例参数：

```text
effective_area_mm2 = 12000.0
```

## 标定曲线模式

正式使用建议优先采用标定曲线，而不是直接使用理论丝杆公式：

```text
force = interpolation(torque, calibration_points)
```

当前 `CalibrationForceCalculator` 支持按扭矩到力的实测点线性插值：

```text
[(torque_1, force_1), (torque_2, force_2), ...]
```

少于两个标定点时：

```text
forceKn = null
status = 未标定
message = 缺少实测标定曲线，不输出正式顶升力
```

## 平衡点判断思路

趋势判断建议：

- 最近点数量达到阈值。
- 角度达到一定范围。
- 扭矩相对波动变小。
- 曲线进入平台段。
- 若扭矩回落，提示滑移风险。

正式模式建议结合以下条件：

- 位移增量变小。
- 扭矩或力增长斜率下降。
- 力值进入目标区间。
- 多个连续采样点稳定。
- 现场标定的预警力和临界力。
- 工人确认该点缝隙和结构状态。

## 当前边界

- 未标定时，顶升力和压力不能作为正式验收值。
- 未标定时不输出正式顶升力、压力和位移结论，只显示扳手原始扭矩/角度和“未标定”提示。
- 真实扳手联调后，应先核对角度缩放，再核对位移，再核对力和压力。
- 预警力临界点需要结合浮置板结构、钢弹簧参数、顶升工艺和现场标定曲线确定。
