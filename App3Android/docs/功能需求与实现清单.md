# 功能需求与实现清单

## 现场业务目标

软件服务于地铁浮置板钢弹簧顶升作业。工人把安卓手机固定或放置在施工可见位置，手机连接 WiFi 扭矩扳手后，实时显示扭矩、转角、顶升力、压力、位移和趋势曲线，并保存每个点位的原始协议数据和工程数据。

## 当前已实现模块

- Jetpack Compose 横屏工作台。
- TCP 客户端。
- 网络诊断：当前 Wi-Fi、本机 IP、默认网关、扳手网段、IP 可达、端口可连接。
- 厂家协议组包、拆包、校验。
- 扭矩转角过程帧解析。
- 最终结果帧解析。
- 电量、设备应答、设备编号、设备状态、螺母计数、位置、特殊模式结果解析。
- 连接保活、结果确认、手机控制、正向顶升、反向回退、停止、时间校准命令组包。
- Room 本地数据库。
- 实时曲线与全屏曲线页面。
- 扳手设置同步显示：`0x15` 中的目标/实际扭矩、目标/实际角度和上下限。

## 不能误判为已完成的内容

- 真实扳手 Wi-Fi 连接和 Android 系统权限处理尚未跑通。
- 真实设备 `0x15` 已抓到并解析；`0x12` 和 `0x55` 仍需继续现场动作抓包确认。
- 顶升力和压力当前不能作为正式工程值。
- CSV / Excel 导出尚需实现。
- 真机安装和现场长时间运行稳定性尚需验证。
