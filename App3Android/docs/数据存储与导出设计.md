# 数据存储与导出设计

## 本机离线存储

Android 端使用 Room 作为本机数据库封装。手机连接扳手 Wi-Fi 后没有互联网，因此所有数据必须保存到本机。

当前数据库：

```text
WrenchDatabase
├── measurement_sessions
└── torque_points
```

## 会话表

`measurement_sessions` 保存一次采集会话：

| 字段 | 含义 |
|---|---|
| `id` | 会话 ID |
| `projectName` | 项目名称 |
| `lineName` | 线路 |
| `sectionName` | 区间 |
| `slabNo` | 浮置板号 |
| `pointNo` | 点位 |
| `operatorName` | 操作员 |
| `deviceSn` | 设备 SN |
| `startTime` | 开始时间戳 |
| `endTime` | 结束时间戳 |
| `connectionMode` | TCP，正式采集只记录真实扳手连接 |
| `resultStatus` | 结果状态 |
| `finalTorqueNm` | 最终扭矩 |
| `finalAngleDeg` | 最终角度 |
| `finalForceKn` | 最终顶升力 |
| `finalPressureMpa` | 最终压力 |
| `finalDisplacementMm` | 最终位移 |

## 采样点表

`torque_points` 保存实时采样点：

| 字段 | 含义 |
|---|---|
| `sessionId` | 关联会话 |
| `timestampMillis` | 采样时间戳 |
| `boltNo` | 螺栓号 |
| `torqueNm` | 扭矩 |
| `angleRaw` | 原始角度 |
| `angleDeg` | 转角 |
| `forceKn` | 顶升力 |
| `pressureMpa` | 压力 |
| `displacementMm` | 位移 |
| `isEffectivePoint` | 是否有效测力点 |
| `rawHex` | 原始协议 HEX |

## 当前已实现

- 创建采集会话。
- 保存扭矩角度点。
- 保存原始 HEX。
- 更新会话摘要。
- 标记最新采样点为有效测力点。
- 查询最近会话。
- 查询指定会话点列。

## 导出建议

CSV 字段建议：

```text
session_id, project_name, line_name, section_name, slab_no, point_no,
timestamp, bolt_no, torque_nm, angle_raw, angle_deg,
displacement_mm, force_kn, pressure_mpa, is_effective_point, raw_hex
```

Excel 建议包含：

- 会话摘要。
- 采样明细。
- 平衡点汇总。
- 原始 HEX。
- 参数版本。
- 曲线截图或曲线数据。

## 数据边界

- 原始 HEX 永远保存，不应只保存解析结果。
- 未标定时，`forceKn` 和 `pressureMpa` 可以为空。
- 正式 APK 不产生演示采集数据，导出内容必须来自真实扳手或历史记录。
- 真机现场数据需要保留设备 SN、工点和操作员信息，方便追溯。
- 应用已关闭 Android 系统自动备份，避免现场历史、原始 HEX 和设备结果被系统云备份带走。
