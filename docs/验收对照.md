- **控制柱**：「远程控制」表头条（开关在右）；正/反转正在执行时实心高亮；停止扳手仍为红色最高强调（规范 A 级优先于渲染）。

## 0.3 第四轮（2026-11-06）：协议核对、平衡点研究图、详细导出、自适应排版

- **协议逐条核对**（对照 `最新协议.docx`，详见 [界面与导出优化方向.md](界面与导出优化方向.md) §2.1）：0x15→0x17 改为收包即回（不排在数据库写入后面，保证 0.5 s 内）；0x06 NAK 只归到 3 s 内刚发的控制指令；0x15 汇总值不再并入实时曲线；解析缓冲先解析后截尾（大块数据不丢帧）；0x10 下限 ≤ 上限校验（0 = 不判）；实时图与导出共用同一运行段切分；一帧一次批量入库。docx 自身 3 处不一致已列出待厂家确认。
- **「扭矩–序号」是什么、为什么去掉**：横轴是接收先后编号（第几个点），不是物理量；找平衡点要看扭矩随**转角**怎么变，序号图用不上，所以屏幕和导出都去掉。接收顺序/时间类的图放在导出里（扭矩/转角/转速/接收间隔 – 接收时间）。
- **屏幕只放两张与平衡点直接相关的图**：扭矩–转角（叠加转折候选：紫色竖虚线 + 菱形 + 两段拟合虚线 +「候选 x° · 未验证」）、斜率–转角（局部 dT/dθ，转折处是台阶；标前/后两段斜率）。两页横轴一致，切换时候选位置对得上。
- **两类「断点」分开画**：转折候选（紫色）vs 数据间断（段内 > 2.5 s 没数据：同色细虚线 + 空心小圆 +「间断 N s」）；运行段之间断开不连线。
- **标签互相避让**：候选标签在竖线四角挑不压曲线、不盖菱形和末点的位置；末点数值放不下就不画（左侧大字已有），不盖候选；前/后斜率标签在线上/线下/延长线外挑不压陡变曲线的位置。640×288、592×336、640×312 @1.3 倍字体与 800×360、914×411、853×480、平板、浅色截图逐张自检。

- **详细导出**（屏幕少、导出多）：新增「拟合明细」「候选扫描」两页（算法中间量全给出，可复核、可调阈值）；「运行段」加平均转速、单直线斜率、最佳两段位置与残差改善（未通过判定也给）；「过程数据」加距上一点、运行段、段内时间、帧号、帧内序号、帧内点数、段内转角增量、帧间转速；图表 8 张（扭矩–转角、斜率–转角、各段叠加、残差改善–候选位置、扭矩/转角/转速/帧接收间隔–接收时间）+ 结果扭矩对照（第五轮起共 10 张，含工况着色两张）。
- **测试**：`LoadingAnalysisTest`（11 项：明显拐点、变硬曲线、直线不强给、空行程剔除、卸载忽略、点数/跨度不足、转角回退、扭矩不升、大跨度分箱限时、明细与候选一致、未通过时仍给最佳位置）；`SessionWorkbookWriterTest`（9 项，含派生列逐行核对、拟合明细/候选扫描、一万帧降采样）；协议/VM/窗口/截图测试同步更新。

## 6. 已知限制 / 待办

1. 没有真机：Wi‑Fi 绑定 socket、握手时延、0x12 实际频率与缩放、正转对应顶升方向都需现场确认。
2. 子网短扫只覆盖 192.168.4.x（沿用既有安全范围）；扳手换网段时靠网关候选 + 手动端点。
3. 远程状态是 App 侧记录（协议无可靠回读）；0x05 状态位未解析成方向灯。
4. 0x50/0x51 已实现但只在设置选了脉冲扳手才开放；RCH 设定扭矩缩放与 0x05 位序待真机确认。
5. 图标/启动页主体位图来自 design-renders 示意稿，待产品方定稿替换。
6. 转折候选阈值（残差改善 ≥ 50%、斜率变化 ≥ 30%、两侧各 ≥ 15% 跨度、有效加载从峰值 5% 起）是开发默认值，**需要用真实数据 + 独立力值/间隙参考试验来定**；导出的「拟合明细」「候选扫描」就是为此准备的。
7. 0x12 约每秒一帧、转角为整数度：帧间转速在低速时量化明显（±1 °/s 级），看趋势用。
