# 算法路线与待验证项

## 目标与当前状态

首先保存可追溯的扭矩—有效转角加载数据，再判断接触面刚分离的位置。当前只实现数据采集、存储、可视化、导出和基础标定插值边界检查，没有已验证的自动分离点结果。

## 物理含义

工具轴向顶升力与隔振器原始支承力不同。刚分离时的工具力对应当时弹簧力；若分离前已发生额外弹簧压缩，它未必等于原始支承力。峰值通常在之后，不能直接替代临界力。

螺杆进给来自相对转角、导程和有效传动比，但还会被弹簧、结构和工具变形吸收，不等于浮置板实际抬升。不得用未经确认的效率/摩擦参数代替整机标定。

## 后续分析模块

1. 保留原始数据，区分正向有效转角、空回、反转、停转、断线及滑移。协议缺少的信息标为未知，不凭曲线外观补造。
2. 用实测标定建立 Tw=aF+b 或稳定单调分段关系。设备、组件、润滑、速度与有效范围必须有版本及匹配条件。训练/验证按整次加载划分，不能随机拆同一曲线相邻点。
3. 承载起点以后，对连续正向段拟合 T(x)=b+m1*x+(m2-m1)*max(0,x-c)。遍历候选 c，限制两侧样本数及角度跨度，与单直线比较 SSE 改善，检查 m1>m2>=0 及新增点后的稳定性。
4. 单直线已足够、候选靠边、与中断/停转/滑移重合或质量不足时返回“未识别”。阈值由预试验确定，不把软件默认值当工程阈值。
5. 先找扭矩曲线的候选转折，再用对应标定换算临界力，避免标定折线本身引入假拐点。未标定可保留候选角和扭矩，但不能输出正式力。
6. 同步独立力参考及真实接触间隙/相对位移；区分局部开口与整体卸载。验证通过前只显示“候选”，不宣称测得初始支承力。

## 数据需求

当前 0x12 不含设备逐点时间、方向和有效段标志。需由厂家确认扭矩与转角的实际测量位置、角度是否连续累计、有效转动/空回口径以及每帧点位时间安排。在这些信息未明确前，不把手机接收时间等同于设备采样时间。

现有原始 HEX 和数据库行序能够支撑后续重解析与算法试验，但不代表厂家未提供的物理量已经可用。CSV 导出可供离线分析；后续算法代码应作为独立可测试模块接入，界面只消费结果和有效状态。
