## 4. 必须遵守（Do / Don’t）

### Do

- 协议缩放分帧处理：0x12 过程扭矩/角按整数；0x10 写角度×10；0x55 结果扭矩÷10；**禁止全局统一÷10**。
- 每次 TCP 连接独立会话；SN 回传后再写；UI 窗口 ≠ 数据库/导出全量。
- 「结束采集 / 断开 App」与「0x01 停止扳手」文案分离；运动指令要确认。
- 导出以真实 `.xlsx` + **原生 Excel 图表** 为主；设置里可选 CSV。
- 无硬件时用协议金样例 + 解析/组包单测 +（可选）Mock TCP 多测几轮。

### Don’t

- 不要改厂家帧格式迁就 UI；不要提交密钥、真实现场库、CAD、抓包。
- 不要在正式界面做模拟采集入口；不要把未验证算法写成「平衡点已确认」。
- 不要 force push / 改仓库可见性；GitHub 推送需用户明确授权。
- 不要用 `MeasurementCsvExporter.buildCsv(recentPoints)` 充当全量导出（最多约 50 点）；全量走分页 `exportSessionCsv` 路径的思想。

## 5. 无硬件时怎么「多测几轮」

已有：Builder 金样例（0x11/0x01/0x10/0x17/0x25/0x33）、Parser、部分 Decoder、TCP 单测、CSV 单测。

建议补强（写入优化方向文档的测试缺口）：

1. **协议金样例全覆盖**：docx 中 0x12 示例逐点解码；0x15/0x55；`A5 A5` 头；粘包/半包/坏校验。  
2. **控制时序单测**：未 0x11 前不应假定 0x01 生效（状态机/文档+日后 ViewModel 门闩）。  
3. **0x15 → 自动 0x17** 确认路径（现 `handleResult` 已发 `resultAck`，需固化测试）。  
4. **Mock TCP**：回放 心跳/SN/多帧 0x12/结果，断言入库点数与导出行数一致。  
5. **角度缩放对照**：0x10 写出 ×10 vs 0x12 读入整数，防止导出/UI 混用。  
6. **禁止**把合成数据接到正式运行数据源；仅 test/debug 源码。
