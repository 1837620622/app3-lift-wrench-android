## 2. 产品与范围

### 2.1 产品定位

- 横屏 Android 工业 HMI：现场工人在浮置板钢弹簧隔振器顶升/调频时，连接厂家 **Wi‑Fi 扭矩扳手**，经 **TCP C 协议**完成读数、安全远程操控、全量入库与带图导出。
- 不是造扳手硬件；不改厂家帧格式；不做 Windows 本阶段。
- **无蓝牙**路径；不以蓝牙替代 Wi‑Fi/TCP。

### 2.2 本阶段 UI 必须交付

- 连上扳手 Wi‑Fi 后自动 TCP，主流程**无端口/IP**。
- **单横屏**工作台：读数 + 扭矩–转角实时图 + 远程控制与启停 + 参数侧滑 + 导出。
- 协议主控面完整可用（见 §8），含远程门闩与运动二次确认。
- 导出以 **xlsx + 原生 Excel 图表** 为主。
- **启动/闪屏页**符合 §5.5（T 形手把扳手 + 规定中文三行）。

### 2.3 本阶段明确不做（见 §11）

平衡点/临界分离算法、正式力值（未标定）、模拟采集作正式入口、主流程多页跳转、英文营销文案、用概念片代替实机验收。

## 3. 连接与网络（写死）

### 3.1 工人主流程（唯一正式路径）

```text
系统设置连接「扳手 Wi‑Fi 热点」
        ↓
App 检测可用网络后，后台自动 TCP
        ↓
内置默认：主机 192.168.4.1 ，端口 7888
        ↓
通信就绪 → 进入单屏工作台（可填/带出板号、测点）
        ↓
工人点「远程控制」启用（0x11）→ 再正转/反转/停止（0x01）
```

### 3.2 硬性规则

| 规则 ID | 内容 |
| --- | --- |
| NET-01 | 默认 TCP 目标写死为 **`192.168.4.1:7888`**（工程常量）。 |
| NET-02 | **正式工人 UI 禁止**出现 IP、端口输入框、端口下拉、端口选择页。 |
| NET-03 | 端口/IP **仅允许**出现在「高级诊断 / 调试」入口（DEBUG 或隐藏手势），且不得作为主流程必经步。 |
| NET-04 | 连接引导页只提示：去系统连扳手 Wi‑Fi、SSID/测点说明、连接状态；**无端口栏**。 |
| NET-05 | 板号、测点是**现场记录字段**，不是通信参数；不得做成“选端口才能控扳手”。 |
| NET-06 | TCP 成功后后台维持心跳（`0x33`）、按需查 SN（`0x25`/`0x26`）；对时 `0x21`/`0x22` 自动，不占用主操作路径。 |

### 3.3 连接状态文案（工人可见，中文）

| 状态 | 文案示例 |
| --- | --- |
| 未连系统 Wi‑Fi | 请先在系统设置连接扳手 Wi‑Fi |
| 正在建链 | 正在连接扳手… |
| TCP 就绪 | 通信就绪 |
| 失败/断开 | 连接失败 / 已断开 — 请确认仍在扳手 Wi‑Fi 下 |
| 远程未开 | 远程未启用（运动按钮禁用） |
| 远程已开 | 远程已启用 |

## 4. 信息架构与单屏分区（写死）

### 4.1 总则

- **默认横屏**；主工作台 **单屏无纵向滚动**（参数用侧滑/模态，历史/设置可另层，但核心操控不跳满屏 Activity 链）。
- 目标设备：工业现场 Android 平板/大屏手机横持；设计基准分辨率建议按 **1920×1080 dp 逻辑比例**缩放，实现可用 `WindowSizeClass` 适配，但**分区相对关系不得打乱**。

### 4.2 分区定义（锁定）

```text
┌──────────────────────────────────────────────────────────────────────────┐
│ A 顶栏：板号 · 测点 · SN · 电量 · Wi‑Fi/通信状态 · 远程状态 · 返回        │
├─────────────┬─────────────────────────────────────────┬──────────────────┤
│ B 左侧读数   │ C 中央主图                               │ D 右侧控制柱      │
│ 扭矩 N·m    │ 扭矩–转角 实时曲线（面积最大）            │ 远程控制 0x11     │
│ 转角 °      │ 转角跨度自适应窗口 · 轴名/单位/新鲜度     │ 正转 / 反转       │
│ 过程/结果摘要│                                         │ 停止（强调）      │
│             │                                         │ 参数（开侧滑）    │
│             │                                         │ 导出              │
└─────────────┴─────────────────────────────────────────┴──────────────────┘
```

说明：底栏若需要「结束会话 / 入库点数 / 安全提示」，高度压缩为单行提示条，**不得**把主图挤成不可读；结束会话与「停止扳手」必须视觉与文案分离。

### 4.3 比例与尺寸建议（实现可微调 ±5%，相对关系锁定）

| 区域 | 建议占比（横宽） | 最小触控 / 高度 |
| --- | --- | --- |
| A 顶栏 | 全宽 | 高度 **56–64 dp**；返回热区 ≥ **48×48 dp** |
| B 读数 | **22–26%** | 主读数数字高度视觉占该柱 ≥ 40%；两行主值（扭矩、转角） |
| C 主图 | **48–54%**（最大） | 绘图区净高建议 ≥ **280 dp**（1080p 横屏） |
| D 控制 | **22–28%** | 主按钮高度 ≥ **52 dp**；按钮间距 ≥ **12 dp**；停止钮视觉权重最高 |

### 4.4 触控目标

| 控件类型 | 最小尺寸 |
| --- | --- |
| 运动类（正转/反转/停止） | ≥ **52×52 dp**，推荐高度 56–64 dp |
| 远程开关 | ≥ **48×48 dp**（可为开关+文字整行热区） |
| 顶栏图标按钮 | ≥ **48×48 dp** |
| 侧滑内表单项 | 行高 ≥ **48 dp** |

手套/现场：控制柱按钮纵向排布，避免依赖精细点击。

### 4.5 读数与主图

- 左侧：**扭矩（N·m）**、**转角（°）** 大号只读；单位固定中文旁注或标准符号，不混英营销词。
- 中央：主系列为 **扭矩–转角**；窗口按**转角跨度自适应**（非死锁最近 50 点）；界面须标明「当前为显示窗口；全量在导出」。
- 新鲜度与心跳分离：曲线停滞要能看出（例如“数据新鲜/延迟”），不得把心跳当过程数据。

## 5. 导航与交互（写死）

### 5.1 导航模型

| 操作 | 行为 |
| --- | --- |
| **返回** | 回到**测点/会话列表**（或上一级列表），不关闭远程机械状态的隐含假设见下 |
| **参数** | **侧滑面板（Side sheet）或居中模态**，**禁止**为参数新开满屏 Activity 作为唯一路径 |
| **导出** | 可在本屏触发；进度/结果用轻量对话框或顶栏提示，完成后可分享/打开文件 |
| **设置 / 高级诊断** | 次级入口；端口仅在此 |
| 核心操控 | **禁止**正转→新页→反转→新页 的多页跳转 |

### 5.2 远程门闩（安全）

| 规则 ID | 内容 |
| --- | --- |
| SAFE-01 | **未启用远程（0x11 开）时，正转/反转禁用**；可点停止（建议始终可点，发 0x01 停止）。 |
| SAFE-02 | 远程开关为工人显式操作；**禁止** TCP 连接成功后偷偷自动 0x11。 |
| SAFE-03 | 正转、反转：**二次确认**对话框（中文说明方向含义与风险）。 |
| SAFE-04 | 写参数（0x10 等）：独立确认，文案须说明会改变设备动作参数。 |
| SAFE-05 | **「结束会话 / 断开 / 返回列表」≠「停止扳手」**。结束会话不得暗示机械已停；若会话结束前仍远程已开，须提示先停止或提供一键停。 |
| SAFE-06 | 停止扳手：最高强调色或描边，文案固定为「停止」或「停止扳手」，与「结束采集」并列时颜色/层级不同。 |

### 5.3 确认框文案骨架（实现可微调用词，语义不可弱化）

- 正转：确认以正转方向驱动扳手？请确认现场安全。  
- 反转：确认以反转方向驱动扳手？请确认现场安全。  
- 写参数：确认将参数写入扳手？写入后影响后续动作。  
- 结束会话：结束仅断开本机会话与采集，**不会自动停止扳手**。是否仍要结束？

### 5.4 参数侧滑内容（最小集）

- 展示/编辑协议允许的 M1/M2 等参数入口（对应 `0x10`；若机型确认需要脉冲参数再开 `0x50`/`0x51`）。  
- 保存 = 确认后下发；取消 = 关闭侧滑不写。  
- 侧滑宽度建议主屏 **36–42%**，遮罩可点关闭（未保存则提示）。


### 5.5 启动 / 闪屏页（写死）

| 规则 ID | 内容 |
| --- | --- |
| SPL-01 | 横屏启动；背景深炭或浅工业中性，**禁止**花哨渐变墙与英文 Slogan。 |
| SPL-02 | 视觉中心：**T 形手把 Wi‑Fi 扭矩扳手**照片级主体（与 App 图标同一造型语言）；**禁止**用套筒/梯形块冒充手把。 |
| SPL-03 | 文案仅中文三行：主标题「**WiFi 扳手**」；副标题「**隔振器顶升调频采集**」；页脚「**传康Kk · 免费供应**」。 |
| SPL-04 | 停留建议 **0.8–1.5 s**（或资源就绪即进）；超时后进入：已连扳手 Wi‑Fi → 工作台；未连 → 连接引导（无端口）。 |
| SPL-05 | 启动页**不**放端口/IP、不放正转反转、不做功能说明书式多段文案。 |
| SPL-06 | 启动页视觉由产品方设计；仓库**不强制**附带概念渲染；验收以本表文案与构图规则为准。 |

气质：安静、产品级、像出厂工业软件开机页，而不是宣传海报。

### 6.5 禁止项

- 主流程 IP/端口控件。  
- 蓝牙图标或文案作为连接主路径。

- 主台纵向长滚动；核心三键藏进溢出菜单。  
- 未开远程仍高亮可点正转/反转。  
- 用「AI 生成感」插画替代真实读数层级。

## 7. 图标与品牌物

### 7.1 App 图标与硬件造型（写死）

**真机参照（产品方提供 · 与 §6.0 同一张）：** `docs/reference-hardware/t-handle-on-isolator.png`  
图中为 **T 形手把**（黑色横握杆 + 竖杆；竖杆上方可有数显/手机支架）；竖杆下方插入/卡在**钢弹簧隔振器**特例上。隔振器是被测对象，**不是** App 图标主体。

写死要求：

- **Logo / 启动页 / 界面品牌物必须尽量贴近该参照图**，与 §6.0 VIS-01～VIS-05 同一标准；可加小型 Wi‑Fi 标识，不得改变 T 手把主体轮廓。

## 8. 协议功能映射表（按钮 → 指令）

帧与缩放细节以 `最新协议.docx` 与 `界面与导出优化方向.md` 为准；**UI 必须暴露的能力**如下。

| UI 控件 / 行为 | 功能码 | 方向 | 规范要求 |
| --- | --- | --- | --- |
| 远程控制 开/关 | **0x11** | App→扳手 | 正式控制柱显式开关；开=启用，关=停止远程 |
| 停止 | **0x01** 停止 | App→扳手 | 始终可达；最高强调 |
| 正转 | **0x01** 正转 | App→扳手 | 依赖远程已开 + 二次确认 |
| 反转 | **0x01** 反转 | App→扳手 | 同上 |
| 参数保存 | **0x10**（及视机型 **0x50/0x51**） | App→扳手 | 侧滑内；强确认；角度写入缩放按协议 |
| 实时曲线 / 左读数 | **0x12** | 扳手→App | 主可视化；入库全量 |
| 结果条 / 导出结果 | **0x15** / **0x55** | 扳手→App | 收 0x15 后自动 **0x17** ACK（工人无感） |
| 顶栏电量 | **0x04** | 扳手→App | 显示 % |
| 顶栏 SN | **0x25** / **0x26** | 双 | 连接后查询并显示 |
| 心跳（后台） | **0x33** | App→扳手 | 防关机；约 1 min 级；无主按钮 |
| 对时（后台） | **0x21** / **0x22** | 双 | 自动 |
| ACK/状态提示 | **0x06** / **0x05** | 扳手→App | 失败/状态可提示，不打断主图 |

**远程门闩（UI 状态机）**

```text
远程=关  →  正转/反转 = Disabled；提示先开远程
远程=开  →  正转/反转 = Enabled（仍要确认）
任意     →  停止可用
结束会话 →  不自动等价于 0x01 停止
```

## 9. 导出与状态文案

### 9.1 导出

| 规则 | 内容 |
| --- | --- |
| 主路径 | **`.xlsx`**，Apache POI XSSF 等生成**真 xlsx**，内嵌 **Excel 原生图表**（非仅改后缀、非仅贴 PNG 充数） |
| 必选图 | 扭矩–转角；扭矩–序号 |
| 建议图 | 转角–序号；扭矩–接收时间（标明时基）；目标 vs 实际（若有结果帧） |
| 数据表 | **全量过程点**；图可降采样，表不砍行 |
| CSV | **设置内可选**；不得取代 xlsx 主路径 |
| 触发 | 控制柱「导出」；成功/失败中文提示 |

### 9.2 关键工人文案原则

- 短、祈使、现场用语；避免开发黑话（如 raw hex）出现在正式层。  
- 安全相关句不可省略（结束≠停机、先远程再运动）。  
- 分离/平衡相关：最多「待分析 / 候选参考」；**禁止**「已确认平衡」。

### 9.3 常用状态句（可直接用）

| 场景 | 文案 |
| --- | --- |
| 导出中 | 正在导出 Excel… |
| 导出成功 | 导出完成（含图表） |
| 导出失败 | 导出失败，请重试或检查存储空间 |
| 未开远程点运动 | 请先启用远程控制 |
| 数据窗口说明 | 曲线为显示窗口（按转角自适应）；完整数据见导出 |
