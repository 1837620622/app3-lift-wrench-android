## 产品是什么

厂家定制 **Wi‑Fi + TCP C 协议** 工业扭矩扳手，用于浮置板**钢弹簧隔振器**顶升/调频测力。不做新扳手硬件；不做蓝牙主路径；**平衡点算法后置**（先攒全量数据 + 带原生图 Excel）。

## 连接（自适应，写死）

1. 工人只连**扳手 Wi‑Fi 热点**。
2. App **自适应探测** TCP：优先 `192.168.4.1:7888`；失败则候选/短扫；C 协议握手成功后**缓存 last-good**。
3. **正式工人 UI 禁止** IP/端口选择；端口仅高级诊断。
4. 板号/测点是记录字段，不是通信参数。

## 单屏横屏 UI（写死）

- 顶栏：板号/测点/SN/电量/Wi‑Fi·自适应通信状态/返回  
- 左：大号扭矩 N·m、转角 °  
- 中：扭矩–转角实时曲线（转角跨度自适应）  
- 右：远程控制(0x11)、正转/反转/停止(0x01)、参数(侧滑)、导出  
- 参数侧滑，禁止核心操作用多页跳转  
- 未 0x11 时正/反禁用；正/反二次确认；结束会话 ≠ 停止扳手  
- 工人界面仅中文；Logo/气质对齐 T 手把真机参照

## 协议面（须进正式 UI）

`0x11` 远程 ↔ `0x01` 停/正/反；`0x10`（及机型确认的 0x50/51）参数；收 `0x12` 过程点全量入库；`0x15/0x55` 结果 + `0x17` ACK；`0x04` 电量；`0x25/26` SN；`0x33` 心跳；对时 `0x21/22` 后台。
